# Персик Вислоухий

Односторінковий сайт-біографія кота породи Scottish Fold.

**Розділи:** паспорт · хроніка по роках · фотоархів · таланти · розклад доби · відгуки очевидців

## Як підставити справжні фото

Усі чотири кадри в галереї намальовані вручну в SVG. Якщо покласти справжні фото
в папку `photos/` під цими іменами, вони автоматично стануть на місце малюнків:

| Файл           | Кадр                        |
|----------------|-----------------------------|
| `photos/1.jpg` | Крупний план, великі очі    |
| `photos/2.jpg` | У вишиванці, на задніх лапах|
| `photos/3.jpg` | На підвіконні               |
| `photos/4.jpg` | В ігровому кріслі           |

Пропорція кадру — 3:4 (вертикальна). Якщо файлу немає, показується малюнок.

## Запуск

Відкрити `index.html` у браузері. Жодних залежностей і збірки — один файл.

## Стек

Чистий HTML + CSS + трохи JS. Шрифти — Unbounded, Nunito, JetBrains Mono (Google Fonts).
Ілюстрації та орнамент — інлайновий SVG.
